SINGLE · 单选 2 分 ✅ 答对啦！
TCP 三次握手过程中，第二次握手时服务器端回复给客户端的报文标志位组合是？
A
只设置 SYN 标志位
B
同时设置 SYN + ACK 两个标志位
C
只设置 ACK 标志位
D
设置 FIN + ACK 标志位
👧 脸脸班长 · 小课堂 班长划重点
🎉 回答正确！+10 XP +1 生命值

口诀：第二次握手 = SYN(我也要同步) + ACK(我收到了)，两个都要有！

👉 A 错误：SYN 只有第一次握手用；
👉 C 错误：单 ACK 是第三次握手；
👉 D 错误：FIN 是断开连接（四次挥手）的标志哦。

❤️这题你选错了（你选了 ❌错误，答案是 ❌错误？不，题目描述是错的，所以正确答案是 ❌，你选对了？）

👉 正经讲： 题目描述是错误的，所以这题正确答案是「❌ 错误」。
三次握手不是冗余，它的本质是：双向确认双方的发送和接收能力都正常。如果只用两次握手，服务器端发完 SYN+ACK 后就建立连接，万一客户端没收到，服务器就会一直空等浪费资源！💡
