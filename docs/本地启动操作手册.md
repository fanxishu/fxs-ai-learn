# 本地启动操作手册

本文记录本机开发时如何启动 / 停止前后端。适合日常联调，详细环境搭建仍可看 [保姆级本地运行指南.md](./保姆级本地运行指南.md)。

---

## 1. 启动前确认

| 项 | 说明 |
| --- | --- |
| 项目根目录 | `e:\xiaochengxu\fxs-ai-learn\fxs-ai-learn` |
| 后端 | FastAPI，默认 `http://127.0.0.1:8000` |
| 前端 | Taro 编译微信小程序，产物在 `frontend/dist` |
| MySQL | 本机默认 `C:\ruanjian\mysql`，端口 `3306` |
| 后端虚拟环境 | `backend\.venv`（没有则按 README 先创建） |
| 环境变量 | 需要 `backend\.env`（可从 `backend\.env.example` 复制） |

PowerShell 建议在**项目根目录**执行脚本。若提示无法运行脚本：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 2. 推荐：一键启动

### 方式 A：双击批处理

在项目根目录双击：

- `start-dev.bat`：启动 MySQL（如未运行）+ 后端 + 前端
- `stop-dev.bat`：停止后端 / 前端

### 方式 B：PowerShell

```powershell
cd e:\xiaochengxu\fxs-ai-learn\fxs-ai-learn
.\scripts\start-dev.ps1
```

脚本会：

1. 检查并启动 MySQL（3306 未监听时）
2. 新开窗口启动后端 `uvicorn`（8000）
3. 新开窗口启动前端 `npm run dev:weapp`

看到类似提示即成功：

```text
已打开后端 / 前端独立窗口
后端: http://127.0.0.1:8000/docs
前端产物: ...\frontend\dist
```

### 停止

```powershell
.\scripts\stop-dev.ps1

# 需要连 MySQL 一起关掉时：
.\scripts\stop-dev.ps1 -IncludeMysql
```

## 3. 分项启动（排障时用）

### 3.1 只启动 MySQL

```powershell
.\scripts\start-mysql.ps1
```

默认读取 `C:\ruanjian\mysql`。若 MySQL 装在别处：

```powershell
$env:FXS_MYSQL_HOME = "D:\your\mysql"
.\scripts\start-mysql.ps1
```

### 3.2 只启动后端

前台运行（当前窗口看日志）：

```powershell
.\scripts\start-backend.ps1
```

后台新窗口：

```powershell
.\scripts\start-backend.ps1 -Detached
```

已手动开过 MySQL 时可跳过检查：

```powershell
.\scripts\start-backend.ps1 -SkipMysql
```

成功标志：

- 窗口出现 `Application startup complete`
- 浏览器打开：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/api/v1/health

### 3.3 只启动前端

```powershell
.\scripts\start-frontend.ps1
# 或
.\scripts\start-frontend.ps1 -Detached
```

成功标志：

```text
Compiled successfully
→ Watching...
```

## 4. 用微信开发者工具预览

1. 打开微信开发者工具 → 导入项目
2. **目录必须选** `frontend/dist`（不是 `frontend`）
3. AppID 可用测试号
4. 详情 → 本地设置 → 勾选 **不校验合法域名、web-view、TLS 版本以及 HTTPS 证书**
5. 前端改代码后会自动编译；开发者工具里点「编译」刷新即可

后端接口基址一般在 `frontend/.env.development`：

```text
TARO_APP_API_BASE=http://127.0.0.1:8000
```

## 5. 脚本清单

| 文件 | 作用 |
| --- | --- |
| `start-dev.bat` / `scripts/start-dev.ps1` | 一键启动 MySQL + 后端 + 前端 |
| `stop-dev.bat` / `scripts/stop-dev.ps1` | 停止后端 / 前端（可选停 MySQL） |
| `scripts/start-mysql.ps1` | 只启 MySQL |
| `scripts/start-backend.ps1` | 只启后端 |
| `scripts/start-frontend.ps1` | 只启前端 |
| `scripts/common.ps1` | 公共函数（端口检测、找 Python 等） |

Python 查找顺序：

1. `backend\.venv\Scripts\python.exe`
2. `C:\ruanjian\python3\python.exe`
3. PATH 中的 `python`

前端使用 `npm run dev:weapp`（本仓库有 `package-lock.json`）。

## 6. 常见问题

### 6.1 后端启动报连不上 3306

先执行：

```powershell
.\scripts\start-mysql.ps1
```

再启动后端。仍失败则检查：

- `C:\ruanjian\mysql\bin\mysqld.exe` 是否存在
- `backend\.env` 里 `DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME` 是否正确

### 6.2 8000 端口被占用

```powershell
.\scripts\stop-dev.ps1
# 或查看占用：
netstat -ano | findstr :8000
```

### 6.3 前端编译成功，但开发者工具空白

- 确认导入的是 `frontend/dist`
- 确认 `npm run dev:weapp` 窗口仍在 Watching
- 开发者工具重新编译一次

### 6.4 接口请求失败 / 登录异常

- 后端是否在跑：打开 http://127.0.0.1:8000/docs
- 是否勾选了「不校验合法域名」
- `backend\.env` 中微信 / JWT / DeepSeek / Tavily 配置是否齐全

### 6.5 想用真实 AI 出题

在 `backend\.env` 中：

```env
USE_MOCK_LLM=false
DEEPSEEK_API_KEY=你的key
ENABLE_WEB_SEARCH=true
TAVILY_API_KEY=你的key
```

改完后重启后端窗口。

## 7. 建议日常流程

```text
1. 双击 start-dev.bat（或执行 .\scripts\start-dev.ps1）
2. 等前端 Compiled successfully
3. 微信开发者工具打开 frontend/dist
4. 联调 / 改代码（前后端均支持热更新）
5. 结束时执行 .\scripts\stop-dev.ps1
```
